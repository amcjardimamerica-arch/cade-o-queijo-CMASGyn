# Inventário das Resoluções nacionais vigentes do CNAS

Inventário em atualização automática pela rotina `src/cnas_corpus.py`.

A relação usa como linha de base a lista oficial de atos vigentes da Portaria
MC nº 833/2022, acrescenta as resoluções posteriores e identifica revogações
expressas. O próximo processamento substituirá este aviso pelo inventário
completo, com fonte, hash, texto pesquisável e classificação de efeito temporal.
